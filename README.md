# 模板支撐互動分析

包含樓板、梁、柱、牆模板檢核，L2 ↔ Y、L3 ↔ X 尺寸連動，以及詳細 Word 計算書匯出。

使用 GitHub Pages 開啟，或下載完整儲存庫後開啟 index.html。所有運算與 Word 函式庫均在本機執行。

原單一跨距模式依提供的 VB 程式移植；新增分階模式使用獨立引擎及 JASS 5（2022）全液壓側壓。適用範圍與公式詳見頁面，不代表整套支撐設計已完成規範符合性認證。

第三方 docx 函式庫授權詳見 vendor/docx-LICENSE.txt。

## 2026-10-18 分階檢核

開啟即顯示牆身分階檢核。依提供的檢核表與梁／牆配置圖，支援 1～5 階高度、H1/B2/H3/H4/B4 間距及一層／二層大格柵。梁側小格柵不參與支撐，梁底與支柱另依原垂直模型檢核。

- `staged-engine.js`：cm、kgf 單位，簡支均布側壓包絡、完整螺桿分攤及階界包絡。
- `staged-ui.js`、`staged.css`：分階輸入、側壓分布、OK/NG 矩陣、原始配置圖及 Word 詳算。
- 預設日本建築學會 JASS 5（2022）9 節全液壓 Ps=W0 h，設計 P(z)=kρ(H−z)/10^6（ρ 用 kg/m³，H、z 用 cm，P 用 kgf/cm²）。k 是工程另加係數；不套用舊版依澆置速度折減表。梁頂板厚保留液壓水頭。自訂上限／均布值須填寫核定依據並明確標示非 JASS 5。
- 螺桿 T=P B4 H4，按一支穿牆對拉桿的完整單側分攤面積計算。本模型不使用舊式的 /2 與 2T。
- 格柵採均布載重近似；集中反力、連續跨、懸臂、接頭與整體穩定須依實際配置另核。階界支承間距須符合相鄰最大配置。
- `node tests/staged-engine.cjs`：74 項獨立數值、受力路徑、單位、階界與錯誤輸入檢查；原引擎另有 55 項回歸。
- 舊版影片對應原單一跨距模式；新增分階操作說明可在內建手冊查詢。

側壓公開原著核對：日本建築學會技術報告集 31(79), 1169–1174（2025），第 1 節 https://www.jstage.jst.go.jp/article/aijt/31/79/31_1169/_pdf/-char/en ；鐵建技術報告 2023 No.37，本文第 1 節 https://www.tekken.co.jp/media/fdbe6cca819fae6f7ad95dccdb8a52ae72916286.pdf 。未收錄規範全文；JASS 5 標示僅指側壓方法。
